# Variational Spread Bot

Telegram-бот: следит за всеми рынками Variational Omni и присылает алерт, когда у пары
низкий спред и OI в заданном диапазоне.

Данные — из публичного API Variational (`/metadata/v2/stats`), ключ не нужен.

## Бесплатный запуск на GitHub Actions (24/7, с авто-рестартом)

1. Создай бота у [@BotFather](https://t.me/BotFather), скопируй токен. Свой id узнай у [@userinfobot](https://t.me/userinfobot).
2. В репозитории: **Settings → Secrets and variables → Actions → New repository secret**:
   - `BOT_TOKEN` — токен бота
   - `ALLOWED_USERS` — необязательно. Не создавай этот секрет, если бот должен быть публичным:
     тогда им может пользоваться кто угодно, у каждого свои фильтры. Если указать id через
     запятую, доступ будет только у них.
3. **Actions → Spread bot → Run workflow**.
4. Напиши боту `/start`.

Как это работает: каждый запуск длится ~5ч40м и штатно завершается, а расписание (раз в 30 минут)
держит следующий запуск в очереди — он стартует сразу после предыдущего. Если бот упал, он
перезапускается внутри сеанса. Настройки и список уже отправленных алертов сохраняются в кэше
Actions и переживают перезапуски.

Нюансы:
- В публичном репозитории минуты Actions бесплатные.
- GitHub отключает расписание, если в репозитории 60 дней не было коммитов. Тогда зайди в
  Actions и нажми **Enable workflow** (или сделай любой коммит).
- Между сеансами бот недоступен ~1 минуту.
- Правила GitHub Actions рассчитаны на CI/CD, а не на постоянно работающих ботов. На практике
  так делают многие, но надёжный вечный хостинг это не гарантирует.

## Локальный запуск

1. Создай бота у [@BotFather](https://t.me/BotFather), скопируй токен.
2. Узнай свой id у [@userinfobot](https://t.me/userinfobot).
3. В папке бота:

```bash
pip install -r requirements.txt
cp .env.example .env      # впиши BOT_TOKEN и ALLOWED_USERS
python bot.py
```

4. Напиши боту `/start`.

Чтобы бот работал круглосуточно, запусти его на VPS (например, через `screen`, `tmux` или systemd).

## Как задавать фильтры

Обычным текстом:

- `ищи OI до 300к и спред 0.02`
- `OI от 50к до 500к, спред 3 bps`
- `спред 0.03` — меняет только спред

Или командами:

| Команда | Что делает |
|---|---|
| `/oi 300k` или `/oi 50k-300k` | макс. (или диапазон) OI в $ |
| `/spread 0.02` или `/spread 2bps` | макс. спред, в % |
| `/vol 10k` | мин. объём за 24ч (отсекает мёртвые пары) |
| `/size base` | по какой котировке считать спред: `base`, `1k`, `100k`, `1m` |
| `/type perp` | `all`, `perp` или `swap` |
| `/cooldown 30` | не повторять алерт по паре чаще, чем раз в N минут |
| `/scan` | что подходит прямо сейчас |
| `/settings` | текущие фильтры |
| `/on`, `/off` | включить / выключить алерты |

По умолчанию: OI до $500k, спред ≤ 0.03%, котировка `base`.

## Как считается

- **OI** = long + short open interest пары (как в API, только позиции трейдеров).
- **Спред** = (ask − bid) / mid × 100% по выбранной котировке. `base` — минимальный
  размер ордера; `100k` покажет реальный спред для крупной сделки.
- Алерт приходит, когда пара **впервые** попала под фильтр. Если она остаётся под ним,
  повторов нет; выпала и снова попала — придёт новый алерт (не чаще cooldown).

## Ограничения

- Variational отдаёт котировки с кэшем до 10 минут, так что это индикативный спред,
  а не реальный стакан в моменте. Перед входом проверь цену в интерфейсе.
- Лимит API: 10 запросов за 10 сек с одного IP — опрос раз в секунду (плюс время ответа) укладывается в лимит, а при 429 бот сам делает паузу.
